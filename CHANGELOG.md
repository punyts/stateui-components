# Changelog

## 0.1.0
- Scaffold: package, build (`buildLibrary` into `dist/components`, `register(window)`), Vitest node and browser configs, and the `mountComponent` test harness.
- `text` atom (`textRole`, `tone`, `align`, `truncate`, `element` with a runtime tag swap), `link` atom (`#` and relative `href`; raises `press`, never navigates) and `divider` atom (`orientation`, optional `_label`, `role="separator"`), each with a German overlay.
- Icon set build: `dist/icons.json` from `@tabler/icons` 3.50.0 (exported as `./icons.json`), the icon alias table and a pixel comparison test.
- `image` atom: inline `data:` picture with `fit`, `ratio`, `radius` and `decorative` (`_alt` required unless decorative).
- Shared control stylesheet `src/shared/css/control.css` (pulled in with `@include "control.css";` through the build's `sharedCssDir`) and the bare `input` and `textarea` atoms: shared `size`, `change` and `input` events with the value, `focus` and `clear` commands, group `control` tokens (`radius`, `border`, `padding.inline`), German overlays.
- `select` (data array or translated static map of options, `multiple`), `checkbox` and `switch` (`role="switch"`) atoms on `control.css` tokens, with `change`, `focus` and `clear` and German overlays; harness option `locales`.
- Test harness: `mountComponent` option `data` sets the document's `data`, so a `<-` link to `$.data` has a target.
- `icon` atom (E4.28): outline and filled icons drawn with `createElementNS` from path data (string or `{ d, fill, stroke, opacity }` paths), the core icon set compiled into the library (`icons/core.js`), the app's icons read from `$.runtime.icons`, shared `tone` and `size`, the `icon.stroke` token, `SUI-RUN-ICON` for an unknown name; `isIconName`, `createIconNames`, `loadIconsFile` and `validateIconNode` (`SUI-STATE-FILLED`) exported from the package.
- `stat` and `avatar` molecules (E4.15) and the shared formatter `src/shared/format/format.ts` (`formatValue`, `toNumber`, `VALUE_FORMATS`, exported from the package): `Intl` number, percent, currency and duration (`m:ss`, `h:mm:ss`) formatting for `$.locale`. `stat` has `format`, `currency` (required when `format` is `currency`), `trend`, `_label`, `_unit`, `value`, `delta` and an icon-mixin trend glyph that `tone` colours only when set; `avatar` has `shape`, `_name`, a `data:`-only `src` and initials from the first and last word of the name.
- `button` atom (E4.4): five variants from the tone properties, `icon` and `iconPosition`, `busy` indicator that keeps the width, `press` and `focus`, tokens `radius`, `padding.inline`, `gap`; the `icon-paths` mixin takes the name of the property that holds the icon name.
- `textField` molecule and the field base (E4.8): `src/shared/css/field.css`, `src/shared/field/field.ts` and the `field` tokens (`label.gap`, `label.width`, `help.size`). `titlePosition` (`top`, `left`, `inner`, `hidden`; reflected), `width` (`fill`, `auto`, `ch`), shared `size` and `density`, `icon`, help text, a polite error region, `aria-describedby`, German overlay. `buildComponents` now emits every `src/shared/**/*.ts` as `shared/**/*.js` beside `components/`, so a controller imports `../shared/<folder>/<file>.js`; the harness accepts camelCase locale file names.
- `badge`, `spinner` and `progress` atoms (E4.5): a status label or count (`count` capped by `max` as `99+`, `dot`, `icon`), a turning ring whose duration comes from `motion.duration.slow` so reduced motion stops it, and a progress bar (`value`, `max`, `indeterminate`, no `aria-valuenow` when indeterminate), each with a German overlay.
- `searchBox` and `menuItem` molecules (E4.16): a search input with icon, clear button, `change`, `search` (Enter), `focus` and `clear`; a menu entry with `icon`, `selected` (`aria-current`), `shortcut`, `_description` and `press`, each with a German overlay.
- `card` molecule (E4.13): a surface with `media`, header (`_title`, `_subtitle`, `actions`), a laid-out body (`children` with `layout`) and `footer`; shared `elevation` (default `raised`) and `density`, `padding`, `selected`, `interactive` (focusable, `press` on click, Enter and Space), tokens `radius`, `padding` and `gap`, German overlay.
- `toast` molecule (E4.27): shared `tone` (default `neutral`), the tone icon defaults (shared helper `src/shared/tone/toneGlyph.ts`), `role="alert"` for `danger` and `warning`, `dismissible`, `_title`, `_text`, `_closeLabel`, the `action` slot and the `close` event, with a German overlay.
- `alert` and `emptyState` molecules (E4.14): `alert` has the tone icon defaults, `role="alert"` for `danger` and `warning`, `dismissible`, `open` (a closed alert leaves the layout), `close`, the `open` and `close` commands, `_closeLabel` and the `actions` slot; `emptyState` has `icon`, `_title`, `_text` and `actions`; both have a German overlay.
- Field contract (E4.31): `invalid` and `valid` events, the `focus` and `clear` commands and the `ui-field-connect` event with the `FieldConnect` interface (`validate`, `reset`, `rebase`, `setManaged`, `setDisabled`, `focus`, `onRelease`, `error`, `value`); runtime property `locked` for the form's disabling; in `src/shared/field/field.ts` and `textField`.
- Field validation and runtime articulation (E4.9): `textField` gets `required`, `minLength`, `maxLength`, `min`, `max` and `pattern` (named list or a regular expression of at most 120 characters), the runtime properties `error`, `touched` and `dirty`, the `change` event, the `validate` and `reset` commands, `_errors` with a German overlay and validation on `change` once touched; the logic is in `src/shared/field/field.ts` and `rules.ts`.
- `skeleton` atom and `loading` on `card` and `stat` (E4.19): `shape` (`text`, `rect`, `circle`), `lines`, `width` (`fill`, `ch`, `%`), `ratio` and the `radius` token; an `aria-hidden` shimmer from the motion tokens that is static under `motion: "reduced"`. `card` (title, subtitle and body) and `stat` (value) show skeletons and set `aria-busy` on the host while `loading`.
- `descriptionList` molecule (E4.23): read-only term and value pairs as `<dl>` with `field` items formatted by the shared formatter and `node` items (a `row: true` template whose `$row` links follow `record`, also when it is re-pointed), `orientation`, `columns` (one column below the `md` breakpoint), `termWidth`, `_empty`, tokens `gap` and `term.color` (group `description`), German overlay. Needs `@punyts/stateui-app` with the `mountApp` change that keeps `$row` links of row templates in the tree.
- `textareaField` and `dateField` molecules (E4.10): both follow the field contract on `createField` with no copied layout or validation. `textareaField` has `rows` (1 to 50) and `autoGrow` and validates `required`, `minLength`, `maxLength` and `pattern`; `dateField` uses `<input type="date">`, writes an ISO date string to `value` and validates `required`, `min` and `max` (ISO dates compared as text, error texts `Too early` and `Too late`). German overlays.
- `checkField` and `switchField` molecules (E4.12): a labelled checkbox and switch on the field base with `checked` as the value, `required` meaning it must be checked, the field contract, `size` and `density`, German overlay.
- `selectField` and `radioField` molecules (E4.11): options from a linked data array (labels not translated) or a static keyed map with `_label` (translated by overlay), `optionValue`, `optionLabel`, `multiple` (select) and `orientation` (radio; reflected), the full field contract with `required` failing on an empty selection, `role="radiogroup"` with native arrow-key movement, German overlays; the shared option logic is `src/shared/field/options.ts` and `focus` now falls back to the checked or first enabled input of a group.
- `tooltip` atom and the shared popover code (E4.18): `src/shared/popover/` (`createPopover`: popover API open and close, CSS anchor positioning from a `placement` or an `anchor` name, Escape and outside-press dismissal, no layout reads; exported from the package) plus the `tip` and `tip-describes` directives that `tooltip` and an icon-only `button` use. `tooltip` has `side` (`top`, `bottom`, `start`, `end`; the name `placement` is reserved by the tree), `delay` (500 ms), `_text` and the slot `trigger`, tokens `padding`, `radius` and `maxsize`; it shows after the delay on hover and at once on focus, hides on Escape, blur and pointer leave, and describes the trigger with `aria-description` (E4.32). An icon-only `button` shows its `_title` the same way. German overlay.
- Catalog checks (E4.17, E4.33): `test/catalog.test.ts` and `test/catalog.browser.test.ts` assert the catalog holds exactly the 16 atoms and 16 molecules of the component spec (a missing or extra component is named), that every example validates and mounts without a reported error (in English and German), that every content text has a German value, that the library builds with no lint error or warning, that no stylesheet references a tone colour token, that component token defaults are references, that icon defaults are core icons, and the accessible-name and runtime-property rules.
- Fix: the `select`, `selectField` and `radioField` controller member `valueOf` is now `optionKeyOf`; `valueOf` shadowed `Object.prototype.valueOf` on the node state and StateUI reported it on every mount.
- Fix: a `card` with no `children` no longer reports an invalid repeat collection on mount.
- Fix: the `select` atom shows a static `value` set at mount (it syncs again when the options render, as `selectField` does).
- Component tokens for the selected and error colours, so no stylesheet names a tone colour: `control.selected.fill` and `control.selected.on`, `field.selected.fill`, `field.selected.on` and `field.error.color`, and `card.selected.fill` and `card.selected.border` (defaults `{color.accent.*}` and `{color.danger.base}`).
