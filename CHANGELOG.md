# Changelog

## Unreleased
- **A `tree` without a row template draws its records**: the `row` slot defaults to `{ component: "text", truncate: 1, "<-_text": "$row.label" }`. Before, a tree without `row` drew empty rows and reported nothing. Found while building the Lumen desktop. Test: `test/composites/tree.browser.test.ts`.
- **`window`** (Lumen stage 2): new composite `window` (`components/composites/window/`, category `layout`, `layout: true`): a title bar with an optional icon and the frame buttons a `controls` list names (`snapLeft`, `snapRight`, `minimize`, `maximize`, `close`), each raising its event; `activate` on a press or on focus from outside. In an `adhoc` layout the title bar moves it and the right edge, bottom edge and corner resize it; only inline styles change during the drag, and on release the placement is written once in pixels and `move` or `resize` is raised. Escape restores; arrow keys move and Shift with an arrow resizes; Enter and a double click raise `maximize`. The pure geometry is `src/shared/window/geometry.ts`. New core icons `layout-sidebar`, `layout-sidebar-right` and `squares`. The two tests that build the whole library or every Tabler icon get a 30 second timeout, since they passed 5 seconds under a parallel run.
- **`panel` content fills a panel of fixed height**: the panel's `.content` is now a column flex box that takes the height left below the header (`flex: 1 1 auto; min-block-size: 0`), and `.body` grows inside it. A child that sizes to its host, such as a `drawing` with a theme `height` of `100%`, now fills a panel whose height comes from its placement or from host code. Before, the content was only as tall as its children, so such a child was drawn 0 px high. This was found while building the Lumen desktop in the example. File: `components/composites/panel/panel.view.css`.
- **An app is its screens (breaking)**: `page` and `outlet` are removed. New composite `app` (the root at `$.app` of an app with screens: `layout: true`, content `_title` for the document title, slot `toasts` defaulting to `toastRegion`, no children); `mountApp` places the screens in its layout host and moves focus on a screen switch. `nav` takes over the responsive menu: `collapseBelow` (`none`, `sm`, `md`, `lg`, `xl`), `open`, runtime `compact` and `_menuLabel` (`Menu`, `Menü`); it measures the layout it is placed in, its button stays above the scrim and its open panel is not capped to the button's width. The shell patterns are screen patterns now (`top-navigation`, `side-navigation`, `marketing`: a panel with a header, a nav, a `content` slot and a footer); `screen/settings` and `dashboardGrid` have a `panel` root; `settingsPage` is now `settingsPanel` (`children.menu`, `children.sections`). Tests: `test/composites/app.browser.test.ts`, `test/composites/nav.browser.test.ts` (the responsive cases), `test/patterns/frame-screens.browser.test.ts`, `test/composed/settings-panel.browser.test.ts`.

- **Pictures in drawings: `drawImage`** (G1.9b of the graphics epic 1): `drawImage` now draws in the SVG and canvas `drawing`. `src` is a `data:` URL of a png, jpeg, gif or webp picture or the reference of such a file of the app's store; the shape's `fileRef` validator already refuses any other type (an SVG among them) as `SUI-STATE-INVALID`, and a linked `src` that delivers one at run time is left out as `SUI-RUN-DRAW`.
