# Changelog

## 0.1.0
- Scaffold: package, build (`buildLibrary` into `dist/components`, `register(window)`), Vitest node and browser configs, and the `mountComponent` test harness.
- `text` atom (`textRole`, `tone`, `align`, `truncate`, `element` with a runtime tag swap), `link` atom (`#` and relative `href`; raises `press`, never navigates) and `divider` atom (`orientation`, optional `_label`, `role="separator"`), each with a German overlay.
- Icon set build: `dist/icons.json` from `@tabler/icons` 3.50.0 (exported as `./icons.json`), the icon alias table and a pixel comparison test.
- `image` atom: inline `data:` picture with `fit`, `ratio`, `radius` and `decorative` (`_alt` required unless decorative).
- Shared control stylesheet `src/shared/css/control.css` (pulled in with `@include "control.css";` through the build's `sharedCssDir`) and the bare `input` and `textarea` atoms: shared `size`, `change` and `input` events with the value, `focus` and `clear` commands, group `control` tokens (`radius`, `border`, `padding.inline`), German overlays.
- `select` (data array or translated static map of options, `multiple`), `checkbox` and `switch` (`role="switch"`) atoms on `control.css` tokens, with `change`, `focus` and `clear` and German overlays; harness option `locales`.
- Test harness: `mountComponent` option `data` sets the document's `data`, so a `<-` link to `$.data` has a target.
- `icon` atom (E4.28): outline and filled icons drawn with `createElementNS` from path data (string or `{ d, fill, stroke, opacity }` paths), the core icon set compiled into the library (`icons/core.js`), the app's icons read from `$.runtime.icons`, shared `tone` and `size`, the `icon.stroke` token, `SUI-RUN-ICON` for an unknown name; `isIconName`, `createIconNames`, `loadIconsFile` and `validateIconNode` (`SUI-STATE-FILLED`) exported from the package.
- `stat` and `avatar` molecules (E4.15) and the shared formatter `src/shared/format/format.ts` (`formatValue`, `toNumber`, `VALUE_FORMATS`, exported from the package): `Intl` number, percent, currency and duration (`m:ss`, `h:mm:ss`) formatting for `$.locale`. `stat` has `format`, `currency` (required when `format` is `currency`), `trend`, `_label`, `_unit`, `value`, `delta` and an icon-mixin trend glyph that `tone` colours only when set; `avatar` has `shape`, `_name`, a `data:`-only `src` and initials from the first and last word of the name.
- `button` atom (E4.4): five variants from the tone properties, `icon` and `iconPosition`, `busy` indicator that keeps the width, `press` and `focus`, tokens `radius`, `padding.inline`, `gap`; the `icon-paths` mixin takes the name of the property that holds the icon name.
- `textField` molecule and the field base (E4.8): `src/shared/css/field.css`, `src/shared/field/field.ts` and the `field` tokens (`label.gap`, `label.width`, `help.size`). `titlePosition` (`top`, `left`, `inner`, `hidden`; reflected), `width` (`fill`, `auto`, `ch`), shared `size` and `density`, `icon`, help text, a polite error region, `aria-describedby`, German overlay. `buildComponents` now emits every `src/shared/**/*.ts` as `shared/**/*.js` beside `components/`, so a controller imports `../shared/<folder>/<file>.js`; the harness accepts camelCase locale file names.
- `badge`, `spinner` and `progress` atoms (E4.5): a status label or count (`count` capped by `max` as `99+`, `dot`, `icon`), a turning ring whose duration comes from `motion.duration.slow` so reduced motion stops it, and a progress bar (`value`, `max`, `indeterminate`, no `aria-valuenow` when indeterminate), each with a German overlay.
- `searchBox` and `menuItem` molecules (E4.16): a search input with icon, clear button, `change`, `search` (Enter), `focus` and `clear`; a menu entry with `icon`, `selected` (`aria-current`), `shortcut`, `_description` and `press`, each with a German overlay.
- `card` molecule (E4.13): a surface with `media`, header (`_title`, `_subtitle`, `actions`), a laid-out body (`children` with `layout`) and `footer`; shared `elevation` (default `raised`) and `density`, `padding`, `selected`, `interactive` (focusable, `press` on click, Enter and Space), tokens `radius`, `padding` and `gap`, German overlay.
- `alert` and `emptyState` molecules (E4.14): `alert` has the tone icon defaults, `role="alert"` for `danger` and `warning`, `dismissible`, `open` (a closed alert leaves the layout), `close`, the `open` and `close` commands, `_closeLabel` and the `actions` slot; `emptyState` has `icon`, `_title`, `_text` and `actions`; both have a German overlay.
- Field validation and runtime articulation (E4.9): `textField` gets `required`, `minLength`, `maxLength`, `min`, `max` and `pattern` (named list or a regular expression of at most 120 characters), the runtime properties `error`, `touched` and `dirty`, the `change` event, the `validate` and `reset` commands, `_errors` with a German overlay and validation on `change` once touched; the logic is in `src/shared/field/field.ts` and `rules.ts`.
